# Учебная практика: Docker, CI/CD, Rust API, GitHub Pages

Восемь заданий из папки «Задание на УП». Общий отчёт для сдачи — `ОТЧЁТ.md` в корне. Краткий отчёт по каждому заданию лежит в его каталоге.

| № | Каталог | Что сделано |
| --- | --- | --- |
| 1 | `01-docker` | Команды Docker и отчёт с определениями |
| 2 | `02-docker-compose` | Nginx + PHP-FPM + MariaDB + phpMyAdmin |
| 3 | `03-docker-images` | Образы Flask и Node.js |
| 4 | `04-book-catalog` | Своё приложение (каталог книг) и его образ |
| 5 | `05-cicd` | Node.js, Dockerfile и GitHub Actions → Docker Hub |
| 6 | `06-rust-crud` | CRUD API на Rust, Postgres, Docker Compose |
| 7 | `07-github-pages` | React + json-server и публикация на GitHub Pages |
| 8 | `08-dev-prod` | Dev/prod: Node.js, Nginx, Postgres, pgAdmin |

Защита отчёта (устный ответ) остаётся за студентом. Пуш на GitHub и Docker Hub тоже: для этого нужны ваши `DOCKERHUB_USERNAME`, `DOCKERHUB_TOKEN` и имя пользователя GitHub. В заданиях 5 и 7 стоят плейсхолдеры `YOUR_DOCKERHUB_USERNAME` и `YOUR_GITHUB_USERNAME`.
