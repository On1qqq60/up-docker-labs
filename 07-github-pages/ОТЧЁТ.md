# Отчёт. Задание 7. GitHub Pages

## Цель

Собрать клиент на React (Create React App, TypeScript), отдавать данные через json-server в разработке и через сырые файлы GitHub в продакшене, опубликовать сборку в ветку `gh-pages`.

## Клиент и локальный API

Приложение инициализируется как `npx create-react-app . --template typescript`. В репозитории уже лежат готовые исходники того же шаблона, чтобы не зависеть от интерактивного генератора.

Серверные файлы — в `src/server`:

- `db/data.json` — `{ "greeting": "Hello world" }`;
- `db/index.js` — отдаёт эти данные функции, которую читает json-server;
- `routes.json` — префикс `/api/*` переписывается в `/$1`;
- скрипт `npm run serve` запускает json-server на порту 3001.

Модуль `src/api/index.ts` описывает типы ответа и функцию `getJson`. В режиме `development` она ходит на `http://localhost:3001/api/data`. `App.tsx` вызывает `api.get.data()` в `useEffect` и показывает `data.greeting`.

Два терминала:

```bash
npm run serve
npm start
```

Клиент открывается на `http://localhost:3000` и показывает `Hello world`.

## Продакшен

`getJson` при `NODE_ENV === 'production'` читает файл по адресу

`https://raw.githubusercontent.com/YOUR_GITHUB_USERNAME/up-docker-labs/gh-pages/static/db/data.json`.

Имя пользователя меняется в `src/config.ts` (`GITHUB_USER`). Если репозиторий называется иначе, меняется и `GITHUB_REPO`.

Скрипт `src/server/scripts/save-json-api.js` (пакет `node-fs`) после сборки копирует данные в `build/static/db`. Он лежит в `src/server/scripts`, а не в `src/scripts`: из этой папки `require('../db')` попадает в `src/server/db`. Команда сборки:

`react-scripts build && npm run save-json-api && shx cp build/index.html build/404.html`

Копия `404.html` нужна для клиентских маршрутов: GitHub Pages на неизвестном адресе отдаёт 404, и эта копия снова запускает React.

`predeploy` очищает `build` через `shx` (на Windows нет команды `rm`), `deploy` публикует каталог пакетом `gh-pages`. В `package.json` поле `homepage` равно `.`, поэтому пути к JS и CSS относительные и не привязаны к чужому имени пользователя из примера методички.

## Публикация

```bash
# в src/config.ts указать свой логин GitHub
npm run deploy
```

Дальше в репозитории: Settings → Pages → Build and deployment → Deploy from branch → ветка `gh-pages` → Save. Сайт появляется по адресу `https://USER.github.io/up-docker-labs/`.

## Вывод

Один и тот же клиент в разработке читает json-server, а в сборке — файл из ветки `gh-pages`. Разветвление сидит в одной функции `getJson` и смотрит на `process.env.NODE_ENV`, которую Create React App выставляет сам.
