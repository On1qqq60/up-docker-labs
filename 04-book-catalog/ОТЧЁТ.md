# Отчёт. Задание 4. Разработка приложения и упаковка его в Docker

## Цель

Разработать приложение и упаковать его в образ Docker.

## Приложение

`book-catalog` — небольшой HTTP-сервис каталога книг на Flask.

- `GET /` — имя сервиса и список маршрутов
- `GET /health` — проверка, что процесс жив
- `GET /books` — список книг
- `POST /books` — добавить книгу, тело `{"title": "...", "author": "..."}`

Стартовый список содержит одну книгу, чтобы ответ был виден сразу после запуска. Данные хранятся в памяти процесса: для учебной упаковки этого достаточно, отдельная база здесь не нужна.

## Образ

```bash
docker build -t book-catalog:latest .
docker run --rm -p 5000:5000 book-catalog:latest
```

Проверка:

```bash
curl http://127.0.0.1:5000/books
curl -X POST http://127.0.0.1:5000/books -H "Content-Type: application/json" -d "{\"title\":\"Compose на практике\",\"author\":\"УП\"}"
```

Образ основан на `python:3.12-slim`. Зависимости ставятся из `requirements.txt` до копирования кода, порт 5000 объявлен через `EXPOSE` и публикуется флагом `-p`.

## Вывод

Приложение любого размера упаковывается одинаково: зафиксировать зависимости, описать команду запуска в Dockerfile и отдать наружу нужный порт. После сборки каталог книг запускается одной командой `docker run` без установленного на хосте Python.
